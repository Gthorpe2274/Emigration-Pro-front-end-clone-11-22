# Emigration Pro API Integration Guide

This guide is for the report generation system to integrate with the Emigration Pro backend.

## Base URL

Production: `https://o6gfg673pq5wu.mocha.app`

## Integration Flow

1. User completes payment on report generation app
2. Stripe redirects to success URL with `?payment_success=true&customer_email={CHECKOUT_EMAIL}`
3. Report app extracts email from URL
4. Report app calls Emigration Pro APIs in sequence:
   - Create assessment → get `assessment_id`
   - Create relocation hub access → get `session_code`
5. Report app displays `session_code` to user
6. User can access permanent hub at `emigrationpro.com/access-hub`

## API Endpoints

### 1. Create Assessment

**Endpoint:** `POST /api/assessments`

**Description:** Creates a new assessment and calculates compatibility score.

**Request Body:**
```json
{
  "user_age": 35,
  "user_job": "Software Engineer",
  "preferred_country": "Portugal",
  "preferred_city": "Lisbon",
  "location_preference": "city",
  "climate_preference": "mediterranean",
  "monthly_budget": 2500,
  "immigration_policies_importance": 5,
  "healthcare_importance": 4,
  "safety_importance": 5,
  "internet_importance": 5,
  "emigration_process_importance": 4,
  "ease_of_immigration_importance": 5,
  "local_acceptance_importance": 4
}
```

**Field Requirements:**

| Field | Type | Required | Validation | Notes |
|-------|------|----------|------------|-------|
| user_age | number | Yes | 18-100 | User's age in years |
| user_job | string | Yes | 1-200 chars | User's occupation |
| preferred_country | string | Yes | 1-100 chars | Target country name |
| preferred_city | string | No | - | Target city name |
| location_preference | enum | Yes | 'beachside', 'rural', 'city' | Geographic preference |
| climate_preference | enum | No | 'tropical', 'seasonal', 'dry', 'mediterranean', 'temperate', 'northern' | Climate type preference |
| monthly_budget | number | No | 100-50000 | Monthly housing budget in USD (defaults to 2000) |
| immigration_policies_importance | number | Yes | 1-5 | Importance rating |
| healthcare_importance | number | Yes | 1-5 | Importance rating |
| safety_importance | number | Yes | 1-5 | Importance rating |
| internet_importance | number | Yes | 1-5 | Importance rating |
| emigration_process_importance | number | Yes | 1-5 | Importance rating |
| ease_of_immigration_importance | number | Yes | 1-5 | Importance rating |
| local_acceptance_importance | number | Yes | 1-5 | Importance rating |

**Success Response (200):**
```json
{
  "success": true,
  "id": 123,
  "score": 87,
  "matchLevel": "very_good"
}
```

**Error Response - Climate Mismatch (400):**
```json
{
  "error": "Climate and country selected are incompatible...",
  "details": "You selected 'tropical' climate but Portugal has a 'mediterranean' climate...",
  "climateConflict": {
    "userPreference": "tropical",
    "countryClimate": "mediterranean",
    "country": "Portugal"
  },
  "requiresReselection": true
}
```

**Error Response - Validation Failed (400):**
```json
{
  "error": "Validation failed",
  "details": [
    {
      "code": "invalid_type",
      "expected": "number",
      "received": "string",
      "path": ["user_age"],
      "message": "Expected number, received string"
    }
  ],
  "message": "The assessment data does not match the required schema"
}
```

### 2. Create Relocation Hub Access

**Endpoint:** `POST /api/relocation-hub/create-access`

**Description:** Creates permanent access to the relocation hub and generates a unique session code.

**Request Body:**
```json
{
  "assessment_id": 123,
  "email": "user@example.com",
  "purchase_confirmed": true
}
```

**Field Requirements:**

| Field | Type | Required | Validation | Notes |
|-------|------|----------|------------|-------|
| assessment_id | number | Yes | - | ID from previous assessment creation |
| email | string | Yes | Valid email | User's email address |
| purchase_confirmed | boolean | No | - | Defaults to true |

**Success Response (200):**
```json
{
  "success": true,
  "session_code": "A1B2-C3D4-E5F6",
  "assessment_id": 123,
  "message": "Permanent relocation hub access created successfully"
}
```

**Important Notes:**
- The `session_code` is generated by Emigration Pro backend (format: XXXX-XXXX-XXXX)
- Do NOT pass a front-end generated session ID
- The session code is unique and provides 5-year access
- Store this session_code and display it prominently to the user

**Error Response - Validation Failed (400):**
```json
{
  "error": "Validation failed",
  "details": [...],
  "message": "The access request data does not match the required schema"
}
```

**Error Response - Generation Failed (500):**
```json
{
  "error": "Failed to generate unique session code"
}
```

### 3. Access Relocation Hub (User Login)

**Endpoint:** `POST /api/relocation-hub/access`

**Description:** Validates email and session code for permanent hub access.

**Request Body:**
```json
{
  "email": "user@example.com",
  "session_code": "A1B2-C3D4-E5F6"
}
```

**Success Response (200):**
```json
{
  "success": true,
  "assessment_id": 123,
  "access_token": "base64encodedtoken",
  "email": "user@example.com",
  "is_permanent": true
}
```

**Error Response - Invalid Credentials (404):**
```json
{
  "error": "Invalid email or session code",
  "success": false
}
```

**Error Response - Expired (403):**
```json
{
  "error": "Access has expired",
  "success": false
}
```

## Example Integration Code

```javascript
async function createEmigrationProAccess(userInput, customerEmail) {
  try {
    // Step 1: Create assessment
    const assessmentResponse = await fetch('https://o6gfg673pq5wu.mocha.app/api/assessments', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        user_age: userInput.age,
        user_job: userInput.occupation,
        preferred_country: userInput.country,
        preferred_city: userInput.city,
        location_preference: userInput.locationType, // 'beachside', 'rural', or 'city'
        climate_preference: userInput.climate, // 'tropical', 'mediterranean', etc.
        monthly_budget: userInput.budget,
        immigration_policies_importance: userInput.immigrationImportance,
        healthcare_importance: userInput.healthcareImportance,
        safety_importance: userInput.safetyImportance,
        internet_importance: userInput.internetImportance,
        emigration_process_importance: userInput.processImportance,
        ease_of_immigration_importance: userInput.easeImportance,
        local_acceptance_importance: userInput.acceptanceImportance
      })
    });
    
    const assessmentData = await assessmentResponse.json();
    
    if (!assessmentData.success) {
      throw new Error(assessmentData.error || 'Assessment creation failed');
    }
    
    const assessmentId = assessmentData.id;
    
    // Step 2: Create relocation hub access
    const accessResponse = await fetch('https://o6gfg673pq5wu.mocha.app/api/relocation-hub/create-access', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        assessment_id: assessmentId,
        email: customerEmail,
        purchase_confirmed: true
      })
    });
    
    const accessData = await accessResponse.json();
    
    if (!accessData.success) {
      throw new Error(accessData.error || 'Access creation failed');
    }
    
    // Step 3: Return session code to display to user
    return {
      success: true,
      sessionCode: accessData.session_code,
      assessmentId: assessmentId,
      email: customerEmail
    };
    
  } catch (error) {
    console.error('Emigration Pro integration error:', error);
    return {
      success: false,
      error: error.message
    };
  }
}
```

## Testing Checklist

Before going live, test the following scenarios:

### ✅ Happy Path
- [ ] Complete payment flow with valid data
- [ ] Assessment created successfully
- [ ] Relocation hub access created successfully
- [ ] Session code displayed to user
- [ ] User can log in to access hub using email and session code

### ✅ Error Handling
- [ ] Invalid age (< 18 or > 100)
- [ ] Invalid budget (< 100 or > 50000)
- [ ] Invalid location_preference (not 'beachside', 'rural', or 'city')
- [ ] Invalid climate_preference
- [ ] Missing required fields
- [ ] Climate mismatch (e.g., tropical climate with northern country)
- [ ] Duplicate email with different assessment

### ✅ Data Validation
- [ ] All importance ratings are between 1-5
- [ ] Country names match expected format
- [ ] Email addresses are valid
- [ ] Monthly budget defaults to 2000 if not provided

## Common Issues

### Issue: "Validation failed" error
**Cause:** Data doesn't match schema requirements
**Solution:** 
- Check that `location_preference` is exactly 'beachside', 'rural', or 'city'
- Check that `climate_preference` is one of the allowed enum values
- Ensure all importance ratings are 1-5, not 0-5
- Verify monthly_budget is between 100-50000

### Issue: "Climate and country selected are incompatible"
**Cause:** User selected climate that doesn't match country's climate type
**Solution:** Either allow user to change their climate preference or choose a different country

### Issue: Session code not displayed
**Cause:** Response parsing issue
**Solution:** The session_code is returned in the response as `session_code` (not `sessionCode`)
