# Images Folder

Place your images here for the "Get a Professional Report" section on the Home page.

## Required Images

1. **elderly-couple-documents.jpg** (or .png)
   - Left side image
   - Shows an elderly couple reviewing emigration documents together
   - Recommended size: 600x400px or larger

2. **couple-report.jpg** (or .png)
   - Right side image  
   - Shows a happy couple reviewing the Emigration Pro Report document
   - Recommended size: 600x400px or larger

## Usage

These images are referenced in `src/react-app/pages/Home.tsx` and will be served from the `/images/` path.

You can use either `.jpg` or `.png` formats - just make sure the filenames match exactly:
- `/images/elderly-couple-documents.jpg` (or `.png`)
- `/images/couple-report.jpg` (or `.png`)
